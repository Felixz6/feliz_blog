# 当前目录文件分析

分析日期：2026-09-23。范围：当前 SRC 研究包中与 DSH、Claude Code、Codex 部署直接相关的目录结构、入口文件及记录；仅整理这三个客户端的状态，不保留其他客户端部署记录。

## 结论

本目录由共享的研究规则、技能知识库、MCP 服务源码、部署/检查脚本组成。三个客户端使用彼此独立的用户级配置与服务副本：DSH 通过激活 profile patch 加载 MCP；Claude Code 使用用户级技能、全局入口和 MCP 配置；Codex 保留技能副本，但 2026-09-21 的最新记录显示本项目 MCP 注册已注销。

当前 DSH 路由已同步为：`recon-mcp` 统一 Gateway 为主搜索源，独立 Netlas、Quake、FOFA 为串行备用，顺序为 Netlas → Quake → FOFA；Playwright 仅为浏览器工具，不属于搜索源。DSH 的服务器实现目录是 `~/.dsh/mcp-servers/`，实际注册和加载顺序由激活 profile 的 `cordis.patch.yml` 决定。

本分析基于本项目文件、活动 DSH profile 和《部署记录.md》的本地记载，不读取或记录任何凭据值。部署日期、测试输出和回滚位置以部署记录中的对应条目为准。
