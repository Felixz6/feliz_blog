“最近”不是目标，可持续地到达才是目标。

  • 面积足够，或仍能回到未来尾部，才允许积极增长
  • 出口过少、即将缩圈、同格败碰直接高额惩罚
  • 领先时保空间，落后且临近终局时提高资源收益
同一张距离场复用多项指标 · 单次 BFS 为 O(nm)05 / 09
普通 BFS 只给最短距离，我们在同一次遍历中同时收集面积、出口、资源、尾部连通。强调“安全空间”的判断：面积够大，或者能持续追随尾巴。这样既保持线性复杂度，又比单一最短路更稳定。
对抗决策

把对手的四种回应都算一遍，选择最坏也能接受的动作

06

Score(move) = minopp ∈ legal Eval(move, opp)

  • 同格碰撞：按护盾状态，再按移动后长度判断
  • 最坏领地：比较双方 BFS 到达时间，取所有回应中的最小领地
  • 封路机会：对手无合法步或仅有必败回应时，提升终局优先级

用最坏情形降低“只猜一条对手路线”的乐观偏差06 / 09
这是主体 AI 最能体现对抗性的部分。每个己方动作面对对手最多四个落点，先处理碰撞，再比较领地。最终采用最小值，而不是平均值；哪怕三个未来很好，只要一个合法回应会让我们立即失败，就淘汰。

四进制 Hash：用一个整数表示整条蛇的形状

07

hash = hash × 4 + direction

1223→107₁₀

给定蛇头坐标，再记录相邻身体节的相对方向序列，就能唯一恢复整条蛇。

int get_shape_hash(Snake *s, int k) { int hash = 0; for (int i = 1; i < k; ++i) hash = hash * 4 + direction(i); return hash; }

刚好匹配约束：k ≤ 9，最多 8 位四进制数，因此 0…4⁸−1 = 65535，可直接作为 vis[16][16][65536] 的下标。

状态 =（蛇头行，蛇头列，形状 Hash）07 / 09
这是算法题的创新点。逐节保存坐标很直观，但判重成本高。相邻蛇节只有四种方向，所以天然是四进制数字。给定蛇头与方向序列，整条蛇唯一确定。k 最大为 9，最多八位，正好落入 16 位无符号范围，对应代码中的 65536。
